Privacy policy

living-room-bot is a personal tool used by its author on a single YouTube account that the author owns.

What it accesses. Through the YouTube Data API it reads the account's playlists and creates, updates, and deletes playlists and playlist items on that account. That is the only Google data it touches.

What it stores. An OAuth refresh token for the account, kept as an encrypted secret in the author's GitHub repository. No other user data is collected, stored, or shared with anyone.

Third parties. None. The tool talks only to Google's YouTube API.

Removing access. Revoke the app at myaccount.google.com/permissions. The tool then stops working immediately.

Questions: open an issue at github.com/nodemadic/living-room-bot.
